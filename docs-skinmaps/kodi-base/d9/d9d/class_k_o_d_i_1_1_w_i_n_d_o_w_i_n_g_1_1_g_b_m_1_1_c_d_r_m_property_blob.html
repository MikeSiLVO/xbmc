Detailed Description

RAII wrapper around a DRM property blob.

Owns both the drm fd and the blob id, and destroys the blob on scope exit. Move-only.

Lifetime note: an atomic commit that references the blob id must complete BEFORE this object is destroyed; DRM requires the blob to be alive for the duration of the commit. Declare at a scope (local or member) that ends AFTER drmModeAtomicCommit returns.

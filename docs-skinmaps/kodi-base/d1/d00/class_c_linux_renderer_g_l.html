◆ VideoBypassesFramebuffer()

bool CLinuxRendererGL::VideoBypassesFramebuffer ( )
inlineoverridevirtual

True when video never reaches the framebuffer: a DRM plane, an Android SurfaceView, the Amlogic video layer. Such a renderer must produce its own capture frame; every other renderer is served by reading the framebuffer.

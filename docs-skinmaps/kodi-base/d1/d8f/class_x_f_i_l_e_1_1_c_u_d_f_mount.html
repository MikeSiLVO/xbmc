Detailed Description

Keeps the UDF volume of an image mounted for as long as the guard lives.

Hold one across a run of reads from the same image - examining a bluray reads one file per playlist - so that they share a single mount instead of re-mounting the volume for each. Costs nothing for a path that does not name a file on a UDF image.

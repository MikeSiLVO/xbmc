Detailed Description

DRM-native multi-planar DMA-BUF descriptor.

Pointed at by VIDEOCODEC_PLATFORM_BUFFER::handle when VIDEOCODEC_PLATFORM_BUFFER::type is VIDEOCODEC_PLATFORM_BUFFER_DRM_PRIME. Layout mirrors the information DRM itself exposes via drmModeAddFB2 + DMA-BUF fds; no ffmpeg types are used so addons need only <drm_fourcc.h> from libdrm.

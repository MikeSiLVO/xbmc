Detailed Description

Tracks which VA surface formats the EGL interop layer can import.

Caller-facing API uses AVPixelFormat (ffmpeg currency), matching the vocabulary used elsewhere in Kodi's codec and renderer code. Internally the AVPixelFormat is mapped to its VA fourcc via kVaFormatTable.

Populated at startup by the probe layer (CVaapi2Texture::TestInteropFormats), which iterates kVaFormatTable and Adds each fourcc that passes a round-trip import test. Queried by the decoder when picking a VA profile.

bool CRPRendererDMAUtils::SupportsScalingMethod ( SCALINGMETHOD method)
static

Check if the DMA renderer supports the specified scaling method.

Note how the graphics API (OpenGL vs. OpenGLES) is abstracted here. The reason is because this interface is exposed to the DMA buffer code, which is currently independent of graphics API (i.e. no use of HAS_GLES in the DMA buffer code).
